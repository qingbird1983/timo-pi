# 术语表（面向非技术读者）

按主题分组，每条给一句话解释。看文档遇到不懂的词先查这里；文档作者第一次使用术语时应链接本表。

## 参照系

- **pi**：一个开源的命令行 AI 编码代理（TypeScript 编写，GitHub: earendil-works/pi）。本项目重写其内核能力，作为功能与兼容性的参照系。
- **PI-Desktop**：第三方社区项目，给 pi 做的桌面工作台（Electron 技术栈）。本项目**只参考其设计思路**，不使用其代码（LGPL 许可证限制）。
- **TUI / GUI**：TUI = 终端里的字符界面（黑窗口）；GUI = 图形窗口界面（本项目的桌面端）。

## pi 的概念

- **内核**：pi 中与界面无关的部分——调用大模型、执行 agent 循环、管理工具与会话。本项目的重写对象。
- **扩展（extension）/ 插件**：第三方写的增强文件，可以给 agent 加工具、加命令、拦截行为。
- **编排类扩展**：不碰界面、只影响"做事流程"的扩展（注册工具、注册命令、事件钩子）。本项目兼容这一类。
- **TUI 类扩展**：需要在终端里画界面的扩展（自定义渲染、小组件）。本项目**不**兼容这一类，改由 GUI 插件面替代。
- **事件钩子（hook）**：内核在关键节点（如"工具即将执行前"）向外发出的通知，插件可借机观察或修改行为。
- **会话（session）**：一次完整的对话记录，落盘成文件，可恢复、可分叉。
- **compaction（压缩）**：对话太长时把早期内容摘要化以腾出空间的机制。
- **TypeBox / JSON Schema**：描述"参数长什么样"的规范语言。JSON Schema 是通用标准，TypeBox 是 pi 用的一个具体写法（内容兼容 JSON Schema）。
- **jiti**：pi 用来在运行时直接加载 TypeScript 扩展文件的工具（Node 生态组件）。

## 大模型接入

- **Provider（模型供应商）**：Anthropic、OpenAI 等。
- **协议适配（wire protocol）**：每家供应商的 HTTP 接口格式不同，需要分别适配。pi 有 5 种协议；本项目 MVP 先做 2 种。
- **模型目录**：可用模型清单（名称、参数上限、价格等），纯数据。
- **OAuth**：一种登录授权方式（浏览器弹窗登录那种），部分供应商用它代替 API 密钥。
- **MCP**：Model Context Protocol，一个开放标准，让外部工具以统一方式接入各类 AI 客户端。配置文件即可接入，无需写代码。
- **rmcp**：MCP 官方 Rust 实现，本项目直接采用，不自研。

## 本项目技术栈

- **Rust**：系统级编程语言，性能好、可编译成独立可执行文件（无需安装运行时）。本项目内核语言。
- **crate**：Rust 的代码包单位。
- **gpui-kit**：Rust 桌面界面组件库（基于 Zed 编辑器的 GPUI 框架），提供现成的按钮、表格、聊天流、diff 展示等组件。
- **NSH（Native Shell）**：Longbridge 出品的跨平台界面框架。本项目用它做**插件界面**：插件用 TSX 写界面，沙箱运行、热更新、带签名。
- **TSX**：一种用类 HTML 语法写界面的代码格式（React 生态通用写法）。
- **QuickJS**：一个可嵌入的小型 JavaScript 引擎。NSH 用它跑插件界面；本项目也用它跑编排类扩展。
- **rolldown / oxc**：Rust 写的前端打包/转译工具链。用于把扩展的 TS 文件（含其依赖）打包成 QuickJS 能直接执行的单文件。
- **沙箱（sandbox）/ 能力（capability）**：让插件代码默认什么都不能做（读文件、联网都要显式授权）的隔离机制。NSH 用 cap-std 实现能力控制。
- **签名包（signed package）**：带数字签名的插件分发包，可验证来源、支持热更新。

## 工程方法

- **ADR（Architecture Decision Record，决策记录）**：一页纸文档，记录"做了什么决定、为什么、放弃了什么备选"。只增不改，推翻旧决策就写新的一篇。
- **文档先行**：先写设计与规范文档并定稿，再写代码。
- **接缝（seam）**：系统里预留的扩展点。MVP 阶段把接缝留对，后面加功能就是"挂上去"而不是"拆了重装"。
- **验收场景**：用非技术语言描述的"做到什么程度算完成"，每个阶段若干条，逐条打勾。
- **fixture（夹具）**：预先录制的固定测试数据。本项目用它离线测试大模型协议适配，保证测试不花钱、结果稳定。
