# ADR-0007：会话格式完全自研、一步到位，不留 pi 格式兼容尾巴

- 状态：定稿
- 日期：2026-10-26
- 关联：ADR-0001；architecture/05；roadmap/phase-1

## 背景

pi 有自己的会话树格式；参考项目 PI-Desktop 为读旧会话把 `pi-coding-agent` 留成"过渡性依赖"，至今未能移除，成为长期包袱。

## 决策

- 会话磁盘格式（`architecture/05-session-format.md`）**从第一天按最终形态设计**：版本化 entry、树形结构、可扩展 payload、向前兼容规则（未知 entry 类型必须跳过不报错）。
- **不提供** pi 会话文件的原生读取/导入；如有需要，未来以独立导入工具实现（backlog 项，非内核职责）。

## 理由

- 会话格式是全项目唯一"后补 = 写迁移工具"的不可逆项（architecture/03 接缝 #1）。
- 兼容旧格式会把上游实现细节钉进内核，重演 PI-Desktop 的过渡依赖困境。

## 后果

- 用户从 pi 迁移时会话历史不延续（可接受：不同产品，工具链可另行导入）。
- Phase 1 必须交付：格式定稿文档 + 向后兼容测试（旧版本文件可读）纳入 CI。
- 格式演进规则：只加不改；破坏性变更须新 major 版本 + 迁移器，且先过 ADR。
