# ADR-0016：插件市场形态与分发边界

- 状态：定稿
- 日期：2026-10-28
- 关联：ADR-0004（B 轨选型）、ADR-0008（范围排除）；roadmap/phase-4；design/phase-4/01、08

## 背景

Phase 4 初版范围写的是「仅本地/URL 分发，不做 marketplace 门户」。2026-10-28 所有者给出目标形态：插件入口应类似 DeepSeek Harness 的插件市场——发现、主题、收藏、已安装、已屏蔽、高级六个页签，卡片展示作者、版本、下载量、分类与截图，安装按钮直接在卡片上。市场是插件生态的入口，不是可选项。

## 决策

1. **做「插件市场」发现页**：左栏「插件市场」（发现）与「插件」（已安装管理）并列；页签：发现、主题、收藏、已安装、已屏蔽、高级。
2. **不自建服务端**：市场目录是一份静态 JSON 索引（HTTPS 托管），社区通过仓库 PR 提交收录；不做账号、支付、评分后端、评论后端。
3. **安装仍以签名包为准**：索引只提供元数据、包 URL 与 sha256；下载后必须通过 NSH 签名校验与清单校验（design/phase-4/02）。索引条目不可执行代码，索引内容不能绕过包签名。
4. **本地状态**：收藏、屏蔽、已安装写在本地；「屏蔽」只影响市场展示与推荐，不等于卸载或禁用。
5. **离线可用**：缓存最近一次索引；无网时展示缓存与已安装插件，安装按钮提示需要网络。
6. **申请收录与导出日志**：申请收录跳转外部表单/仓库 issue；导出日志导出本地诊断压缩包，不内建提交后端。

## 理由

- 插件要被发现才有生态；只给本地安装会让插件系统停在开发者自用阶段。
- 静态索引 + 签名包的组合把「分发」与「信任」分开：索引可以托管在任何静态站点，信任仍由 ed25519 签名保证，不需要运营服务端。
- 不做评论/评分后端，避免在单机产品里引入账号、审核与持久化服务。

## 后果

- 正面：插件有发现、分类、收藏、屏蔽的完整产品面；安装路径与既有签名校验完全一致；服务端成本为零。
- 代价：下载量/星标等统计由索引维护者提供，宿主只读展示，无法保证实时性；评论只能外链。
- 范围修订：roadmap/phase-4 §2 的「不做 marketplace 门户」改为「不做交易、账号、评分与评论后端」；新增 design/phase-4/08。
- 安全边界不变：未签名/篡改/撤销包仍拒载；市场页不能提升插件权限，挡位与授权仍由安装向导决定。
