# ADR-0017：调研参考截图入库 docs/research/assets/

- 状态：定稿
- 日期：2026-10-29
- 关联：standards/08 §7（>1MB 二进制资产须先写 ADR）；standards/01（文档规范）；research/07、research/08

## 背景

视觉精修批次（Phase 4 收口后启动）以 research/07 §8「所有者视觉方向 v1」为素材基线，其中 17 处引用 `assets/direction-*.png` 方向截图（ZCode/DSH/旧 Timo 实拍，2026-10-27~28 拍摄）。截图此前只存在于本机、从未入库：断线恢复时发现已提交的 research 文档相对链接全部悬空。目录 20 张共约 3.5MB，其中 `direction-old-timo-theme.png` 约 1.4MB，触发 standards/08「超过 1MB 的二进制资产须先写 ADR」。本机无无损 PNG 压缩工具链，有损转 JPEG 会损失主题/配色参考价值。

## 决策

1. **参考截图随 research 文档入库**，存放于 `docs/research/assets/`，文档内用相对链接引用；不入库则文档不可交付。
2. **单张 ≤ 2MB**：超过先压缩再入库（保真优先于体积；压缩不了的登记豁免）。**目录总预算 20MB**：research/07 声明"持续增补"，超预算先清最旧、引用最少的图。
3. **只收"已建档引用"的图**：孤儿图片不入库（与 docs 孤儿文档同纪律）；删除引用时同步删图。
4. **截图是调研快照，不追新**：上游产品改版不回补图片，引用处已注明拍摄日期；结论冻结走 research 新篇（standards/08 §2），不换图。
5. 图片不计入 docs 文档总数（standards/08 已定：按 `.md` 计）；CHANGELOG 随所属 docs 批次记一次，不逐图记。

## 理由

- 单人单机项目，仓库即资产库：素材是视觉决策的**证据记录**（所有者拍板的依据），与 ADR 同级需要长期可追溯；外部图床不可控且与"一切入库可回溯"的项目习惯相悖。
- 3.5MB 一次性成本可接受：截图为静态快照不会增长性重写，增长受 §2 总预算约束。
- 视觉精修启动时距拍摄可能已有数周，本机文件无备份一旦丢失，「所有者视觉方向」失去基线。

## 后果

- 正面：research 文档链接随仓库走，任何会话/机器可交付；素材有预算、有登记、有清理机制。
- 代价：仓库体积 +3.5MB；其中 1.4MB 单张凭本 ADR 豁免 1MB 线。
- 维护：research/07/08 增补截图时按 §2 执行；超 20MB 触发清理并在 CHANGELOG 登记。
