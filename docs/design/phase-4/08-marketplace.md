# 设计 08：插件市场（发现页）

- 状态：草稿（2026-10-28）
- 关联：ADR-0016；roadmap/phase-4 D6；design/phase-4/01、02、03
- 定位：市场负责**发现与安装入口**，已安装管理仍是 01；安装校验与授权完全复用 02/03。

## 1. 目标与边界

左栏「插件市场」提供：发现、主题、收藏、已安装、已屏蔽、高级六个页签；分类/搜索/排序；卡片直接安装；收藏与屏蔽本地持久化；索引缓存与离线降级。

不做：账号、支付、评分/评论后端、上传托管、跨插件通信。索引是静态 JSON，包托管在任意 HTTPS 静态站点。

## 2. 市场索引协议（schema 1）

```json
{
  "schema": 1,
  "market_version": "1.0",
  "updated_at": "2026-10-28T12:00:00Z",
  "plugins": [
    {
      "id": "session-search",
      "name": "会话搜索",
      "kind": "gui",
      "version": "1.0.0",
      "author": { "name": "timo", "url": "https://example.com" },
      "description": "搜索历史会话并打开。",
      "categories": ["会话与消息", "工具与能力"],
      "screenshots": ["https://example.com/shot-1.png"],
      "stats": { "downloads_30d": 1200, "stars": 36 },
      "requires": { "timo": ">=0.4.0", "api": 1 },
      "package": {
        "url": "https://example.com/session-search-1.0.0.nshpkg",
        "sha256": "<64hex>"
      },
      "manifest_url": "https://example.com/session-search/manifest.json",
      "homepage": "https://example.com/session-search",
      "discussion": "https://example.com/session-search/discussions/1"
    }
  ]
}
```

| 字段 | 规则 |
|---|---|
| `schema` | 必须为 `1`；未知主版本整份索引拒绝（E750） |
| `id` | 与 manifest 一致，全局唯一 |
| `kind` | `gui` / `orchestration`，用于卡片徽标与筛选 |
| `categories` | 必须命中固定分类；未知分类忽略并记 E752 |
| `screenshots` | HTTPS，最多 4 张；宿主下载后本地缓存 |
| `stats` | 只读展示；缺失显示「—」，宿主不统计 |
| `requires.timo/api` | 不满足时卡片禁用安装并说明（E754） |
| `package` | 必须是 `.nshpkg` + sha256；下载后先比对 sha256 再走签名校验 |
| `manifest_url` | 可选；缺失时安装向包内/同目录查找清单，失败 E713 |
| `discussion` | 外链「评论」入口；不做内建评论 |

- 索引 URL 默认内置官方地址；「高级」页可改（仅 HTTPS），改后立即刷新。
- 索引本身不签名：HTTPS + 包签名 + sha256 已覆盖代码完整性；索引只能改变展示与下载来源，不能提升权限。

## 3. 分类与页签

固定分类（v1）：AGI 架构探索、UI 增强、用量与计费、主题与外观、模型与账号接入、身份与通信、会话与消息、记忆、工具与能力。

| 页签 | 内容 |
|---|---|
| 发现 | 全部索引条目；分类 chips + 搜索 + 排序（推荐/下载/星标/更新） |
| 主题 | 分类 = 主题与外观 |
| 收藏 | 本地收藏 id 列表（可取消收藏） |
| 已安装 | 跳转/复用 01 的已安装列表（含启停、挡位、诊断） |
| 已屏蔽 | 本地屏蔽列表，可恢复；屏蔽不等于卸载 |
| 高级 | 索引 URL、缓存清理、刷新、开发模式、导出诊断 |

- 搜索：名称/描述/作者/id 的大小写不敏感子串；与分类筛选叠加。
- 卡片状态：未安装（安装）、已安装（打开/管理）、更新可用（更新）、版本不满足（禁用）、已屏蔽（不出现）。

### 3.1 卡片与排版（错落式瀑布流）

- **瀑布流布局**：卡片高度由内容决定，多列错落排列；≥1200px 三列、900~1199 两列、<900 单列。**不使用等高网格**。
- 顺序横向优先（左→右）：新卡片放入当前最短列；同一索引数据刷新后顺序稳定，不重排用户已看到的位置。
- 卡片内容：标题、作者/版本、下载/星标、描述（最多 5 行，超出「展开」）、0~2 张截图（按原比例，不强制统一高度）、版本要求、分类标签、评论、安装按钮。
- 卡片内边距与圆角走宿主 token；截图加载失败显示同宽占位，不改变列宽。
- 骨架屏按列宽生成不等高占位，加载完成后卡片不出现大幅跳动。
- 已安装页（01）仍是分组列表，不用瀑布流；两种排版不要混用。

## 4. 拉取、缓存与离线

```text
启动 → 读缓存（如有）立即渲染 → 后台 GET 索引（If-None-Match/updated_at）
     → 200：校验 schema → 原子写索引缓存 + 截图缓存
     → 304：保持缓存
     → 失败：保持缓存，页头提示「在线目录暂不可用」
```

- 缓存位置：`<data_dir>/market/index.json`、`<data_dir>/market/shots/<id>-<n>`。
- 截图按需下载（卡片进入可视区），失败显示占位，不阻塞卡片。
- 离线：可浏览缓存、管理已安装；安装按钮禁用并提示需要网络。
- 索引刷新节流：手动刷新最多 1 次/分钟；不做后台自动轮询。

## 5. 安装流程（卡片直接安装）

```text
点击安装 → 下载 .nshpkg + manifest → 校验 sha256
        → 进入 01 §6 安装向导（签名/清单/挡位/确认）
        → 落盘、授权、启用 → 卡片变「打开」
```

- 下载到临时文件，大小上限 64MB；重定向 ≤3，仅 HTTPS。
- 下载失败/校验失败：卡片显示 E753/E711，不落盘。
- `requires` 不满足：安装按钮禁用，悬停说明所需版本。
- 已安装同 id：显示「更新」；版本相同显示「已安装」；已安装但被禁用显示「已禁用」。

## 6. 收藏、屏蔽与本地状态

`<data_dir>/market/state.json`：

```json
{
  "schema": 1,
  "favorites": ["session-search"],
  "blocked": ["noisy-plugin"],
  "installed_seen": ["subagent"]
}
```

- 收藏/屏蔽只写本地；屏蔽后从发现/主题/收藏隐藏，已安装页仍可见。
- 屏蔽不影响加载；禁用/卸载仍走 01。
- 索引条目被移除但本地仍安装：已安装页保留，市场显示「已下架」。

## 7. 安全与失败处理

- 索引与截图只读展示；任何字段都不能作为可执行内容注入。
- 包必须通过 02 的签名/清单/降级校验；市场不能跳过或降低挡位。
- 外链（作者主页、评论）用系统浏览器打开，不在应用内加载。
- 错误码：E750 索引格式非法；E751 索引拉取失败（保留缓存）；E752 未知分类（忽略）；E753 包下载失败；E754 版本不满足；E755 条目与已安装冲突（显示管理入口）。
- 索引刷新失败不弹模态，只在页头提示；连续 3 次失败停止本轮自动刷新。

## 8. 验收断言（D6）

- 首次启动无缓存且断网：市场显示空态与「需要网络」提示，不崩溃。
- 有缓存断网：卡片可浏览、已安装可管理，安装按钮禁用。
- 索引 schema=2：整份拒绝并提示 E750，不部分渲染。
- 分类 chips 与搜索叠加结果正确；收藏/屏蔽重启后保持。
- 卡片安装：sha256 不符停在下载校验（E753），签名不符停在向导（E711），两者都不落盘。
- 已安装条目在市场中显示「打开」，与 01 的启停状态一致。
- 索引指向已下架包：卡片显示 E753，可从已安装页卸载。
